# 高并发秒杀场景解决方案（1元买奶茶等电商活动）

## 一、问题分析

### 1.1 核心挑战
- **瞬时高并发**：活动开始瞬间可能有数万甚至数十万请求
- **库存有限**：商品数量远小于请求数（如1000杯奶茶，10万用户抢购）
- **数据一致性**：防止超卖、重复购买
- **系统稳定性**：避免服务器崩溃、数据库压力过大

### 1.2 典型场景
- 秒杀活动（1元奶茶、限时特价）
- 抢购活动（限量商品、首发商品）
- 优惠券发放

```javascript
function debounce(func, wait) {
    let timeout;
    return function() {
        clearTimeout(timeout);
        timeout = setTimeout(() => func.apply(this, arguments), wait);
    };
}

// 按钮点击防抖
```

#### 3.1.2 滑动窗口限流
```java
// Redis实现滑动窗口限流
public class SlidingWindowRateLimiter {
    private RedisTemplate<String, String> redisTemplate;
    
    public boolean isAllowed(String userId, int maxRequests, int windowSeconds) {
        String key = "rate_limit:" + userId;
        long now = System.currentTimeMillis();
        long windowStart = now - windowSeconds * 1000;
        
        // 移除窗口外的记录
        redisTemplate.opsForZSet().removeRangeByScore(key, 0, windowStart);
        
        // 统计窗口内请求数
        Long count = redisTemplate.opsForZSet().count(key, windowStart, now);
        
        if (count < maxRequests) {
            // 记录本次请求
            redisTemplate.opsForZSet().add(key, UUID.randomUUID().toString(), now);
            redisTemplate.expire(key, windowSeconds, TimeUnit.SECONDS);
            return true;
        }
        return false;
    }
}
```

### 4.2 库存扣减方案

#### 4.2.1 Redis原子操作（推荐）
```java
@Service
public class SeckillService {
    @Autowired
    private RedisTemplate<String, String> redisTemplate;
    
    /**
     * 使用Redis Lua脚本保证原子性
     */
    public boolean deductStock(Long activityId, Long userId) {
        String stockKey = "stock:" + activityId;
        String orderKey = "order:" + activityId + ":" + userId;
        
        // Lua脚本：原子性检查库存并扣减
        String luaScript = 
            "local stock = redis.call('get', KEYS[1]) " +
            "if stock and tonumber(stock) > 0 then " +
            "    redis.call('decr', KEYS[1]) " +
            "    redis.call('set', KEYS[2], '1', 'EX', 3600) " +
            "    return 1 " +
            "else " +
            "    return 0 " +
            "end";
        
        DefaultRedisScript<Long> script = new DefaultRedisScript<>();
        script.setScriptText(luaScript);
        script.setResultType(Long.class);
        
        Long result = redisTemplate.execute(script, 
            Arrays.asList(stockKey, orderKey));
        
        return result != null && result == 1;
    }
}
```

#### 4.2.2 分布式锁方案
```java
@Service
public class SeckillService {
    @Autowired
    private RedissonClient redissonClient;
    
    public boolean deductStockWithLock(Long activityId, Long userId) {
        String lockKey = "lock:stock:" + activityId;
        RLock lock = redissonClient.getLock(lockKey);
        
        try {
            // 尝试加锁，最多等待100ms，锁定时间10秒
            if (lock.tryLock(100, 10000, TimeUnit.MILLISECONDS)) {
                try {
                    // 检查库存
                    String stockKey = "stock:" + activityId;
                    String stock = redisTemplate.opsForValue().get(stockKey);
                    
                    if (stock != null && Integer.parseInt(stock) > 0) {
                        // 扣减库存
                        redisTemplate.opsForValue().decrement(stockKey);
                        // 记录订单
                        createOrder(activityId, userId);
                        return true;
                    }
                    return false;
                } finally {
                    lock.unlock();
                }
            }
            return false;
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            return false;
        }
    }
}
```

### 4.3 异步处理订单

#### 4.3.1 消息队列削峰
```java
@Service
public class SeckillService {
    @Autowired
    private RabbitTemplate rabbitTemplate;
    
    /**
     * 秒杀流程：
     * 1. Redis预扣库存（快速响应）
     * 2. 发送消息到队列（异步处理）
     * 3. 返回"抢购成功，订单处理中"
     */
    public SeckillResult seckill(Long activityId, Long userId) {
        // 1. 快速检查：用户是否已购买
        if (hasPurchased(activityId, userId)) {
            return SeckillResult.fail("您已参与过本次活动");
        }
        
        // 2. Redis原子扣减库存
        if (!deductStock(activityId, userId)) {
            return SeckillResult.fail("商品已售罄");
        }
        
        // 3. 发送订单消息到队列
        SeckillMessage message = new SeckillMessage(activityId, userId);
        rabbitTemplate.convertAndSend("seckill.exchange", "seckill.order", message);
        
        // 4. 立即返回成功（订单异步处理）
        return SeckillResult.success("抢购成功，订单处理中...");
    }
}

// 订单消费者
@Component
@RabbitListener(queues = "seckill.order.queue")
public class OrderConsumer {
```

```java
// 热点数据永不过期 + 异步更新
public Activity getActivity(Long activityId) {
    String key = "activity:" + activityId;
    Activity activity = (Activity) redisTemplate.opsForValue().get(key);
    
    if (activity == null) {
        // 使用分布式锁，防止缓存击穿
        RLock lock = redissonClient.getLock("lock:activity:" + activityId);
        try {
            if (lock.tryLock()) {
                // 双重检查
                activity = (Activity) redisTemplate.opsForValue().get(key);
                if (activity == null) {
                    activity = activityMapper.selectById(activityId);
                    // 设置较长的过期时间，后台异步刷新
                    redisTemplate.opsForValue().set(key, activity, 1, TimeUnit.HOURS);
                }
            }
        } finally {
            lock.unlock();
        }
    }
    return activity;
}
```

## 九、完整秒杀流程示例

### 9.1 流程图
```
用户点击购买
    ↓
前端：防抖 + 倒计时检查
    ↓
网关：IP限流 + 用户限流
    ↓
应用层：验证码校验（如需要）
    ↓
Redis：检查用户是否已购买（去重）
    ↓
Redis：原子扣减库存（Lua脚本）
    ↓
发送消息到MQ（异步创建订单）
    ↓
立即返回"抢购成功"
    ↓
MQ消费者：创建订单（数据库）
    ↓
订单创建成功：发送通知
订单创建失败：回滚库存
```

### 9.2 核心代码示例
```java
@RestController
@RequestMapping("/api/seckill")
public class SeckillController {
    
    @Autowired
    private SeckillService seckillService;
    
    @PostMapping("/purchase")
    public Result purchase(@RequestBody SeckillRequest request) {
        // 1. 参数校验
        if (!validateRequest(request)) {
            return Result.fail("参数错误");
        }
        
        // 2. 执行秒杀
        SeckillResult result = seckillService.seckill(
            request.getActivityId(), 
            request.getUserId()
        );
        
        return Result.from(result);
    }
}

@Service
public class SeckillService {
    
    @Autowired
    private RedisTemplate<String, String> redisTemplate;
    
    @Autowired
    private RabbitTemplate rabbitTemplate;
    
    public SeckillResult seckill(Long activityId, Long userId) {
        // 1. 检查用户是否已购买
        String orderKey = "order:" + activityId + ":" + userId;
        if (redisTemplate.hasKey(orderKey)) {
            return SeckillResult.fail("您已参与过本次活动");
        }
        
        // 2. 原子扣减库存
        String stockKey = "stock:" + activityId;
        Long stock = redisTemplate.opsForValue().decrement(stockKey);
        
        if (stock < 0) {
            // 库存不足，回滚
            redisTemplate.opsForValue().increment(stockKey);
            return SeckillResult.fail("商品已售罄");
        }
        
        // 3. 标记用户已购买
        redisTemplate.opsForValue().set(orderKey, "1", 1, TimeUnit.HOURS);
        
        // 4. 发送订单消息
        SeckillMessage message = new SeckillMessage(activityId, userId);
        rabbitTemplate.convertAndSend("seckill.exchange", "seckill.order", message);
        
        return SeckillResult.success("抢购成功，订单处理中...");
    }
}
```

## 十、总结与最佳实践

### 10.1 核心原则
1. **前端限流**：减少无效请求
2. **网关限流**：保护后端服务
3. **缓存优先**：Redis处理大部分请求
4. **异步处理**：订单创建异步化，快速响应
5. **数据库保护**：避免直接承受高并发压力

### 10.2 技术选型建议
- **缓存**：Redis（单机/集群）
- **消息队列**：RabbitMQ（中小规模）或 Kafka（大规模）
- **限流**：Nginx + Redis + Guava RateLimiter
- **分布式锁**：Redisson
- **监控**：Prometheus + Grafana

### 10.3 性能目标
- **响应时间**：< 100ms（Redis操作）
- **QPS**：单机支持 5000+ QPS
- **可用性**：99.9%+
- **数据一致性**：最终一致性（订单异步处理）
